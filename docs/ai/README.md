# AI 简报独立研究入口

这个目录用于先在固定数据上研究简报算法，确认效果后再接入产品。现有正文、旧分块和分析缓存是实验材料；旧模型结果不是标准答案。此次没有重做生产算法、修改模型配置或触发新的生成／转录。

## 新窗口先读

1. [`ai算法研究.md`](./ai算法研究.md)：用户目的、当前源码流程、已发现问题、候选策略、评估与复现要求。
2. [`data/2026-09/manifest.json`](./data/2026-09/manifest.json)：固定样本范围、导出时间、源码版本、文件行数及哈希、现有缓存的统计边界。
3. [`data/2026-09/episodes.csv`](./data/2026-09/episodes.csv)：九月有效订阅池的全部节目，包括没有正文和不相关节目。
4. [`data/2026-09/sources.jsonl`](./data/2026-09/sources.jsonl)：可直接实验的完整正文及字幕结构。

先做数据检查与小样本策略对照，随后才做整月分析。不要直接点击当前月报生成，把大量现有调用当成算法实验。

## 固定快照包含什么

周期为香港时间 `2026-09-01 00:00 ≤ 节目发布时间 < 2026-10-01 00:00`。这份导出包含原始 111 行节目，17 行关联订阅已不存在；当前产品口径去重后 78 期／36 份正文，已有 AI／LLM 筛选相关 32 份。全部正文共 1,300,505 字符，旧分块 135 段；相关正文共 1,245,580 字符、127 段。全量数据保留，不只导出相关节目，实际计数以 manifest 为准。

| 文件 | 用途与边界 |
| --- | --- |
| `manifest.json` | 固定周期、导出时刻、源码版本、文件哈希与数量、旧分块参数、基线关注及缓存统计。 |
| `episodes.csv` | 有效订阅、去重后的节目元数据；正文是否可用、现有筛选标签／理由、正文哈希与关联来源 ID。 |
| `raw_episodes.csv` | 九月 111 行原始数据库节目及有效范围／去重映射，保留已删除订阅关联等异常记录；`orphaned_feed/in_product_corpus` 区分范围，不等于产品材料数量。 |
| `sources.jsonl` | 正文来源记录。`full_text` 是当前流程实际分析文本；同时保留原始 `raw_text`、`raw_segments`、规范化 `segments` 与转录来源信息。 |
| `raw_transcripts.jsonl` | 63 份原始转录及字幕段，含重复副本、12 份孤立节目正文、其他记录借用的转录；`used_by_source_ids` 对应主样本，使用字段白名单，不含认证信息。 |
| `baseline_chunks.jsonl` | 当前 12,000 字符算法的分块文本、编号、起止位置、正文与分块哈希，用于复现和检查上下文切断。 |
| `cache_inventory.csv` | 按来源／分块观察已有筛选、摘录、观点缓存及模型、耗时、token。 |
| `cached_records.jsonl` | 已保存缓存的原内容；只读导出，不补齐缺失缓存、不启动模型。 |

JSONL 每行是一个 JSON 对象，可逐行读取，无需将长文稿塞进 CSV。CSV 使用 UTF-8，字段需用 CSV 解析器读取。分块 `start/end` 是 **Python Unicode 字符偏移**，不能直接当作 JavaScript UTF-16 索引；验证拼回正文时使用 Python。

缓存来自不同历史运行，可能部分缺失；统计是“现存缓存所记录的调用样本”，不是整个月实际总费用，不包含所有未保存失败的成本。现有筛选判断、缓存摘要不能全部当成用户认可的结果。导出为只读逐次采集，不是数据库事务快照；文件完成后冻结并记录哈希，之后所有对照使用同一份文件。

```powershell
.\.venv\Scripts\python.exe scripts/export_briefing_research.py --owner-id 6abafe97d178845460c2ae0f --period-start 2026-09-01
```

此命令只读取已有数据，不调用 LLM 或转录。默认输出 `docs/ai/data/2026-09/`，目录已存在时拒绝覆盖；若确需新快照，用 `--output` 指定新目录。账号 ID 是本次样本范围，切换账号会改变研究材料，不要输出或复制 API 密钥与登录令牌。

# AI 简报：跳过错误与断点续跑

更新：2026-10-01。适用于当前周期简报的摘录、观点分析和最终五模式编排。算法研究背景见 [AI 算法研究](./ai算法研究.md)。

## 用户可见行为

- 单条内容无法通过引文或字段校验时，舍弃该条，保留同一响应中其他合格条目，不为了这一条重生成整段。
- 模型返回空内容、JSON 无法解析、缺少必要列表或摘要等整段结构错误，最多调用两次；失败后跳过该分块，继续其他材料。空内容的用量和结束原因也保存到调用记录中；不会用空白的 assistant 消息重试。
- 报告显示已跳过的条目数量和未完成的分析分块数量。分块数按阶段累计：同一正文在摘录、观点阶段都失败会算两个分析分块。
- 观点分析有独立进度，并显示复用了多少段；摘录完成不再代表全部处理完成。
- 原话匹配标准保持不变。被舍弃的原话和解释不进入候选或最终展示，也不会用近似匹配冒充原话。

## 如何继续

回到同一周／月与关注范围，点击“继续生成当前模式”或重新生成；已有部分报告有整段缺口时，点击“补跑未完成部分”。不需要删除任务或缓存。

系统自动读取成功分块，只调用尚未完成或上次整段失败的分块，然后重新生成所选模式的最终编排。历史任务继续保留原来的失败状态，新尝试产生新任务记录，成功缓存跨进程重启保留。

有个别条目被舍弃、其余结果有效的分块，标为 `partial` 并视为已处理，不在每次生成时反复追求那一条。整段无法解析的分块标为 `skipped`，下次生成才补跑。只查看页面、材料或报告不会补跑。

这不是后台无限自动重试：网络断开、模型服务错误、认证配置等异常仍提示任务失败，已保存分块可以在下次生成时复用。前置关注筛选仍遵循原来的严格规则，不把无法判断的节目自动当作不相关。

## 后台留下哪些记录

所有路径相对仓库根目录。`.runtime` 是本地运行数据，不随 Git 提交。

| 记录 | 位置 | 内容 |
| --- | --- | --- |
| 任务状态 | MongoDB `tasks` 集合 | 任务 ID、账号、周期、开始／结束时间、进度、错误和最终结果。 |
| 摘录缓存 | `backend/.runtime/briefing-reports/extraction-v1/<正文哈希前20位>/C001.json` | 摘要、合格术语／原话／资料、被舍弃条目、状态、usage、调用记录引用。 |
| 观点缓存 | `backend/.runtime/briefing-lab/notes/<正文哈希前20位>/C001.json` | 摘要、合格观点及原话位置、被舍弃条目、状态、usage、调用记录引用。 |
| 每次分块调用 | 上述缓存目录的 `attempts/C001/<随机ID>.json` | 节目、阶段、正文哈希、分块偏移、提示词与实际输入、原始模型返回、每次响应的 usage／耗时／校验错误，以及被舍弃条目。 |
| 每次模式编排 | `backend/.runtime/briefing-reports/content-modes-v1/attempts/<随机ID>.json` | 模式、账号、周期、输入、原始响应、被舍弃条目及校验结果。 |
| 已保存报告 | `backend/.runtime/briefing-reports/content-modes-v1/reports/<报告ID>.json` | 报告内容和 `analysis` 覆盖信息，含模式调用记录的相对路径。 |
| 前置筛选失败 | 现有筛选缓存中的 `C001.failure.json` | 话题匹配失败的模型返回与错误，沿用原机制。 |

每次分块尝试使用新日志文件名，补跑成功不会覆盖旧的失败调用记录。旧版缓存没有 `analysis_status` 时，按已通过当时校验的完成记录读取，避免重跑九月已有成果。

## 状态与校验

`completed` 表示该段结构和条目校验通过；`partial` 表示部分条目被舍弃；`skipped` 表示整段结构校验在两次调用后仍失败。它们只描述处理结果，不代表人工认定内容质量合格。

报告 `analysis` 保存分阶段的总分块、完成数、整段跳过数、缺失数、被舍弃条目数，以及最终模式舍弃数。最终模型同时收到覆盖信息，不得把有缺口的分析描述为全文完整阅读。

缓存以正文哈希区分，修改正文会重新处理。当前摘录有版本目录，观点缓存仍沿用原有规则；将来修改研究算法或提示词时，需要另建版本目录，不能误用旧结果。

## 记录的边界

- 新记录从本次改动生效后开始。过去失败的摘录／观点原始响应没有持久化，无法事后恢复。
- 校验失败返回会保存。请求没有取得响应时，任务记录保留错误，但不会伪造一份模型响应；进程被强制终止时，尚未返回的请求也无法恢复。
- 缓存中的 usage 描述产出该缓存的调用。计算包含历史失败在内的累计费用，应读取每次调用日志，不要与缓存或任务结果重复相加。
- 日志包含正文和提示词，使用本地文件排查；不会保存客户端密钥或认证请求头。
- 本轮用模拟模型响应测试局部舍弃、两次失败、跨服务实例续跑、只读访问和审计记录。没有为验证修改重新调用九月的真实模型。

## 周报与月报

周期按香港时区的节目发布时间计算：周一至下周一为一周，每月1日至次月1日为一个月，区间右侧不包含。日期栏以周报／月报、左右切换和可横向滑动的日期标签浏览，不使用原生范围滑杆；切换日期保留阅读风格和内容模式。

当前周期展示去重后的全部材料数、有正文数、筛选后纳入数，以及已有全文分析数。不同RSS订阅可使用相同guid，不因此合并或借用彼此的文稿；标准YouTube／B站视频编号可跨重复订阅识别同一期。材料清单显示节目、发布日期、正文和分析状态、纳入理由；没有正文的节目可以初筛，但不会被当作已分析内容。

日期切换只读取已保存结果，不调用模型。不同周期、关注组合和正文指纹对应独立报告；没有该范围的结果时明确提示生成，不回退其他日期的报告。此前固定十篇的对照样例与缓存保留兼容。

账号可在“简报设置”中选择每周或每月自动生成。周期结束后的00:05（香港时间）起，后台每五分钟检查，按最新关注生成最近结束周期的五种模式；同周期已有完整结果则复用。开启前结束的历史周期不会自动补生成。任务按账号和周期持久去重，失败隔一小时重试，最多三次；全局AI关闭时暂停新生成。自动任务依赖后台服务运行，停机后只补最近符合条件的周期，仍可手动生成。

## 我的关注与标题初筛

“关注与简报”支持添加、移除与停用话题，也支持最多200字的具体问题，例如“AI如何改变团队分工”。启用的问题实际进入筛选和汇总提示词。移除重复且含义模糊的报告标签筛选、卡片标签；收藏不受影响。

生成先收集本周期所有节目，以标题、节目名和已有简介每20期一批宽松筛选。只排除明显偏离用户关注的内容与整期纯广告；关注AI时经营、算力、组织等延伸主题可纳入。有赞助不等于整期广告；无法确认时保留。初筛理由明确属于标题判断，不冒充正文证据。筛选缓存按标题、简介、提示词和关注组合保存。未启用话题时仍排除纯广告。

初筛返回每期一次 `include/exclude/uncertain` 与简短理由，校验遗漏、重复、未知节目与无效话题。筛选失败明确报错，不能把失败当作“不相关”。查看周期、保存关注和读取分析均不调用模型。

## 一份单篇记录，三个使用场景

流程为：收集节目 → 标题初筛 → 逐篇完整分析 → 跨篇汇总。进度显示当前阶段、完成/总篇数、复用数、新分析数及失败数。周报、月报均从单篇结果组成紧凑材料，再分别生成五种模式；不再把整批文稿重复发送给每个汇总模式。

`EpisodeAnalysisService` 将结果存入 `backend/.runtime/briefing-reports/episode-analysis/<key>.json`。key包含全文SHA-256、分析结构/提示词版本、模型名称、endpoint和生成参数；不包含周期、兴趣或用户。相同正文跨单篇/周报/月报及重复订阅复用。正文或分析配置变化产生新记录；每次读取重新绑定当前节目的出处、偏移和可用音频时间。

文件锁在并发分析同一篇时去重，成功结果原子写入，进程退出释放锁。共享缓存不等于共享私人报告：访问单篇前仍验证当前用户的节目可见性；周期报告、任务和收藏继续按账号隔离。旧片段解读单独标为 `legacy_reading`，可阅读但不能冒充新全文缓存。

全文分析保存核心摘要、议题回答与条件、原话、新词/方法、资料。原文依据必须逐字匹配正文；音频时间可空，纯文本照常分析。超过配置输入预算明确失败，不默默截取头尾。单篇默认不联网补事实，跨篇汇总仅从已保存的实际证据引用。

## 原话浮窗

“原话依据”与“提及原话”打开卡组，左右展示略微倾斜的相邻原话预览。点击邻卡、下一段按钮、左右方向键，或从标题/留白处鼠标拖动均可切换，触屏支持横滑；首尾停止。当前内容仍保留出处、译文、回听和文稿定位。点击外围和Esc关闭，减少动画偏好下取消切换动画。

桌面浮窗固定650×560px，手机与矮屏按可用视口缩小，长短原话和语言切换都不改变窗口尺寸。标题、语言工具、出处和底部操作各自固定区域，只有正文滚动；短句保留留白，长文提示滚动并在尚未读完时轻微渐隐。保留原话分段，不缩小字体或裁掉全文。选中原话后可划下重点，每段原话和译文分别保留一处划线，仅在本次浮窗阅读中保留，可清除；不会改写原文或保存成永久笔记。

## 内容模式决定编辑策略，风格决定呈现

五种内容模式共用周期取材、关注筛选和单篇全文分析，使用各自的编辑提示词与保存结果。核心提要综合整期摘要和议题；有原文依据不等于已准确理解主旨，仍需人工抽查。原话模式保留简短背景与逐字引用。首页先展示最多六条，可展开其余内容；证据和详细资料按需阅读，材料不足不凑数量。

| 内容模式 | 要回答的问题 |
| --- | --- |
| 核心提要 | 这期主要在讨论什么，提出什么判断，有哪些依据与条件？ |
| 原话精选 | 哪些完整原话值得记下，并能直接回听？ |
| 共性与分歧 | 哪些节目在讨论同一个具体问题，观点如何关联或不同？ |
| 新词与方法 | 出现了什么术语或方法，这期是怎么使用它的？ |
| 提到的资料 | 实际提到了什么书、文章、论文或工具，可以继续读什么？ |

此前十篇对照复核结果为10条核心提要、10句原话、4组有证据的联系、8个新词与方法、10份资料，77处引文均核对原文与节目时间。共性模式包含两组共同点和两组互补，没有为了凑“分歧”制造相反观点。周期报告的数量随实际相关正文而变化，不要求每一期凑相同数量。

2026-10-01对进行中的09月28日—10月04日周期实际试生成：8期都有文稿，AI／LLM正文筛选纳入5期、排除3期历史节目；相关内容共21分块、210,747字符。五种模式为5条核心、8句原话、2组有边界的互补观点、8个新词与方法、8份资料。原文引句均核对偏移和来源，35条英文依据补中文译文；删去两组证据不足的联系，原模型稿与审查依据另存保留。周期尚未结束，自动周报将在周期结束后纳入届时材料。

视觉风格属于独立的风格库，同一模式的内容可以换一种样子呈现，不重新调用模型。阅读页工具栏在“导出 PDF”旁直接提供“阅读风格”，收藏页也提供同一入口；切换即时生效并保存为账号偏好，周报、月报和收藏共用，手机端同样可用。单篇解读继续使用独立的文章排版。风格选择与内容模式选择分别保存。现有排版继续保留，新增风格只需要适配已有内容块，不需要复制分析流程：

| 版式 | 阅读结构 |
| --- | --- |
| 留白 | 一句主摘录，其余分层排布，使用留白和平线 |
| 大字 | 宽幅原话逐句展开，突出文字本身 |
| 清单 | 单列阅读行，快速选择想继续听的内容 |
| 双栏 | 两列原话并排阅读 |
| 纸面 | 应用深色外壳里的浅色阅读页 |
| 报刊 | 暖白底色、衬线标题与双栏，形成报刊式阅读页 |
| 便笺 | 浅黄与浅绿便笺，每块集中展示一个要点 |

来源字体至少13px，原话以20–24px为主，焦点摘录进一步放大。双栏卡片等宽等高，文字区和底部操作对齐；手机恢复自然高度。生成主题设置收起，首页不展示全文字符数、任务配置或资料查证工作状态。

卡片直接展示观点与来源，不再重复“AI”等笼统标签。关注问题影响生成前取材，阅读风格仅改变展示。

灰色爱心常驻卡片操作区，收藏后填充彩色，支持再次取消；收藏存后端账号快照，支持跨周期和跨设备读取。旧浏览器记录只按ID迁移，无法唯一确认内容时保留旧记录并提示未解决，不猜测来源。阅读布局也存为个人后端偏好。

## 全文取证与精选

此前对照样本为十篇完整文稿：281,782字符、32个连续分块，材料指纹 `aed02d4c400f1a3f`。当前周期入口从订阅库读取所选日期内的材料，不固定限制十篇取材。核心提要优先每期一个主旨；其他模式按内容价值选取，不要求每期占一张。

实际节目采用全文单篇缓存；旧Sxx实验样本保留原来的分块管线以兼容已有档案。生成说明展示实际模式模板与输入说明。`BriefingReadingService.generate_edition` 仍保留旧摘句接口，但不是当前周/月报的底层分析。

真实节目完整简报现在一次请求组织五栏目；只生成一个栏目时按需请求。汇总只发送已保存的议题、条件与候选ID，普通观点不重复传全文引文。原话、概念、资料选ID后由服务器回填；跨篇比较引用原有议题。公共规则和材料保持在消息前缀，关注问题与栏目任务放最后。五份报告共享generation_id，调用用量仅在第一份计一次，shared_usage保留整个调用的明细。

单篇和新汇总的结构失败不自动重写整份结果；局部无效项记录后跳过，其余内容保留。引用只允许唯一可确认的逗号/空白差异恢复，数字旁逗号、缺词、改词及歧义匹配不猜测，展示始终回填真实原文。缓存和思考token由供应商实际响应记录，缺失表示未知。

核心提要必须交代具体主张与条件，附对应的正文证据；跨节目分析必须有不同节目的直接支持，不能仅凭共同提到“AI”就称为共识或分歧。明显字幕错词与不完整含义不进入结果。缩短引文只能取原始候选中的连续完整句，并重新定位正文偏移与字幕时间；不能AI改写后标为原话。

说话人由已校验候选继承，身份无法确认就不补人名。播客旁白不能误归为其讨论的历史人物。译文不强设字数下限，避免为凑字数添加原话没有的意义。本轮人工复核保留原始模型结果和编辑理由，原始文稿不改写；用户生成的三份旧模板结果保留原文件，另存带原报告ID、实际调用记录和修订依据的复核副本。

跨节目联系明确标为AI归纳，必须关联至少两个不同来源的原话。没有确切联系就不显示，不制造一致观点、争论或相互印证。资料必须在文稿中实际提及，未验证的链接不能生成或猜测。

## 感兴趣再读单篇

“读这期”在AI简报内部打开解读；传统节目详情的“AI 解读”读取同一份数据，展示组件也共用。先展示简短导读，再按实际内容提供分议题摘要、概念/方法及可展开的原话和资料，不再限制长访谈只能12个议题。议题、概念和资料引用稳定段落ID，由服务器回填全部对应原文；精选原话才需要模型逐字摘录及翻译。传统“模板摘要”与这份共享分析分开保留。

读取已有结果不调用模型。未生成或分析版本失效时显示生成按钮，传完整文稿进行分析；有新缓存时不提供无意义的重复生成按钮。生成需要user/admin权限并尊重AI总开关，viewer只读。任务切换页面后仍能恢复，完成后载入已保存结果。

周期报告的任务与页面状态也按自然周／月独立：生成十月月报不会阻塞九月月报，不会覆盖九月内容，也不会把十月的进度或报错显示到九月。当前页面只轮询所选周期的任务，切换回来恢复查看；同一周期的重复生成仍拦截。自动报告与手动报告使用相同的周期去重规则。升级前缺少周期记录的在途任务继续沿用原去重规则，完成后新任务启用周期隔离。

读取周期报告按账号、周期类型和起始日期查找：优先显示与当前材料和配置匹配的已保存版本，否则显示这个周期最新的历史版本。材料、关注话题、模型或提示词的变化只影响后续生成和缓存命中，不能使已付费生成的报告消失。历史报告的来源、内容和原有统计保留，接口通过 `matches_current_selection` 标明版本是否匹配；页面提示变化，用户可以自主生成新版本。读取和切换栏目不调用模型。

界面语言与内容语言分开：切换中文／英文会更新栏目、操作、筛选、设置、日期、阅读风格和已保存任务的产品进度文案；节目标题、完整文稿、原话与已生成的 AI 内容保留原文，不重新生成。周期标签和日期遵循同一报告时区；系统摘要模板名称及已有双语参数标签跟随界面语言，自定义模板名称保留。

“从这里听”复用跨节目定位播放；无法应用内播放时提供原平台时间链接。“查看原文”仍展示保存的完整正文／字幕及定位。单篇阅读与传统节目详情承担不同阅读层级，播放动作才切换至传统模式。

## 封面与导出

封面优先已落地的 `/api/media/covers/` 图片；相对路径不是无效URL。远程图不携带本地页面Referer，失败后尝试订阅图片，最终使用CSS文字／平台图标，避免不存在的占位图造成二次裂图。

PDF默认完整导出当前模式全部已保存内容，包括每条原话依据、译文和完整来源索引，自动多页；可选舒适或紧凑密度。纸面单栏、报刊双栏沿用阅读主题CSS，长条目可以跨页，不能因放不下一页而消失。预览和下载使用相同内容与打印规则，不调用模型。

一页/两页仅作为明确标注的“精选”选项保留，仍按实际高度取舍并标明未收录数量。密度选项用于完整报告，固定页数精选沿用旧版式。完整模式的HTML为连续阅读预览，PDF由浏览器自然分页。

旧五种分类报告与原话精选后端接口保留兼容，当前入口使用内容模式与风格库。详细端点见 [API文档](./api.md)，此前内容方案见 [方案记录](./briefing-report-plan.md)。

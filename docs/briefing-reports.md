# AI 简报：原话精选与五种阅读排版

2026-10-01。入口 `/briefing`，旧 `/briefing-lab` 链接兼容。原左侧标识、模式切换、节目与订阅、底部设置完整保留。

## 首页先做取舍

首页显示同一份少量精选原话：默认三至五条，主题材料不足时允许更少，不以数量凑内容。每条配一句简短背景、节目出处和回听入口，英文忠实译文明确标注。完整单集标题、原文、资料、复制收藏等按需展开。

五个版本是同一份精选的五种视觉排版，切换不会调模型或替换内容：

| 版式 | 阅读结构 |
| --- | --- |
| 留白 | 一句主摘录，其余分层排布，使用留白和平线 |
| 大字 | 宽幅原话逐句展开，突出文字本身 |
| 清单 | 单列阅读行，快速选择想继续听的内容 |
| 双栏 | 两列原话并排阅读 |
| 纸面 | 应用深色外壳里的浅色阅读页 |

来源字体至少13px，原话以20–24px为主，焦点摘录进一步放大。生成主题设置收起，首页不展示全文字符数、任务配置或资料查证工作状态。

## 全文取证与精选

本轮沿用十篇已取得完整文稿的固定对照样本：281,782字符、32个连续分块，材料指纹 `aed02d4c400f1a3f`。默认不要求每一期各占一张。

全文抽取缓存先提供原话和证据，`BriefingReadingService` 再用一次编辑调用筛选值得读的内容、压缩背景。明显字幕错词与不完整含义不进入精选。缩短引文只能取原始候选中的连续完整句，并重新定位正文偏移与字幕时间；不能AI改写后标为原话。

说话人由已校验候选继承，身份无法确认就不补人名。播客旁白不能误归为其讨论的历史人物。译文不强设字数下限，避免为凑字数添加原话没有的意义。人工复核保留原始模型结果和编辑理由，原始文稿不改写。

跨节目共同点至多两条，必须关联来自至少两个不同来源的精选原话，明确标为“AI归纳”。没有确切共同点就不显示，不制造一致观点、争论或相互印证。

## 感兴趣再读单篇

“读这期”在AI简报内部进入单篇解读，保留左侧AI状态；返回时保留排版与阅读位置。单篇先给一句要点，再给一至三个有依据的解读；对应原话与进一步资料主动展开，短片不足三点不凑数。

读取已有结果不调用模型。未生成时给明确生成按钮，使用已读全文分块记录与校验过的证据生成，不能拿标题冒充全文解读。任务按账号隔离，失败保留旧结果，断线保留任务并重试。

“从这里听”复用跨节目定位播放；无法应用内播放时提供原平台时间链接。“查看原文”仍展示保存的完整正文／字幕及定位。单篇阅读与传统节目详情承担不同阅读层级，播放动作才切换至传统模式。

## 封面与导出

封面优先已落地的 `/api/media/covers/` 图片；相对路径不是无效URL。远程图不携带本地页面Referer，失败后尝试订阅图片，最终使用CSS文字／平台图标，避免不存在的占位图造成二次裂图。

一／两页PDF导出同一份保存的精选，预览与下载不重新生成。一页保留精选；两页版在第二页补上原话对照、共同话题和完整材料来源。纸面精选原话增大到14pt，去掉空标题与重复说明，保留短背景、出处及时间链接。浏览器实测高度后分页，不截断原句、不无限缩字号强塞；英文对照无法整块放入时标明收录数量，并保留完整文稿链接。

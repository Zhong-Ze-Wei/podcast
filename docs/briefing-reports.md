# AI 简报：五种内容报告

2026-10-01。当前入口是 `/briefing`；旧 `/briefing-lab` 链接也进入同一页面。实现沿用 [内容与版式方案](./briefing-report-plan.md)，取代此前问答式实验的前端入口。

## 页面与五种编排

完整保留原左侧：PodMaster 标识、传统／AI 简报切换、节目与订阅列表、设置、添加播客。版本选择、关注项、主题和导出都在右侧。

| 版本 | 网页主要内容 | 用途 |
| --- | --- | --- |
| 本期速览 | 新词、金句、提到的资料分区，附短背景 | 快速扫读不同节目里的具体内容 |
| 逐期摘录 | 每期一张节目卡，放入该期概念、原话和资料 | 明确哪一期说了什么 |
| 本期新词 | 白话解释、节目中的用法、原话证据 | 理解并积累术语 |
| 金句摘录 | 原话、明确标注的译文、当时的上下文 | 复制、收藏、回听 |
| 提到的资料 | 文章、书、论文、工具或网站，标明提及关系 | 继续阅读；未确认链接保持待确认 |

五版来自同一份材料和同一次专门抽取，按不同侧重点编排内容块；模型不自由写 CSS，也不生成五篇聊天回答。主题为可选关键词，不要求用户组织成问题。未选的关注项不会出现在新生成的报告中，专门版本会解释对应关注项未开启。

## 实际材料与生成流程

当前对照样本固定为最近取得完整文稿的十篇材料，共 **281,782 字符、32 个连续分块**，包含长节目和短片。页面明确标短片和真实时长；不声称十篇都是完整长播客。材料指纹为 `aed02d4c400f1a3f`，后续刷新订阅不会悄悄替换这个对照样本。

本轮实际使用现有模型配置完成 32/32 分块的概念、金句、资料和背景抽取。逐字引文与正文匹配，时间来自保存的字幕段；段落级时间不冒充句子级精度。抽取缓存按正文指纹保存，复用时重新绑定当前节目，避免同文稿缓存带错来源。

另有人工审查记录：剔除字幕错词、意义不完整的句子、无法确认的人名与数字，保留原始抽取和修改依据。原始文稿没有改写。缓存提取记录的成功调用用量共 354,997 token，含已保存的修正调用；失败调用未计入，因此不能当作完整账单。

生成使用既有任务队列。任务与个人结果按账号隔离，报告绑定材料指纹；断网继续保留任务，失败保留之前的报告。已有抽取可复用，切版及读取报告不调用模型。关注项和主题改变后，需要点生成才应用到新报告，页面会提示旧结果仍在显示。

## 来源、原文与回听

每块直接展示节目名、单集标题和已有时间。点击“打开节目”进入传统模式对应详情；“从这里听”先取完整单集再切换音源，等待元数据就绪后定位，不沿用该节目的个人历史位置。

RSS／本地音频复用播放器，YouTube 复用现有音频流。无法在应用播放的材料提供原平台链接；YouTube、B站链接带时间。音频由本地切到远程时继续保留定位时间。PDF 中的应用链接也使用 `/episodes/<id>?t=<seconds>`，公开原平台链接另行保留。

“查看原文”展示保存的完整正文／字幕，定位并突出当前摘录。英文摘录区分原话与中文译文，说话人不能确定时不补猜测姓名。金句收藏存在当前浏览器并按账号分开，不等同于节目收藏。

## 一页／两页 PDF

网页与报告使用两套固定 CSS。报告是 A4 白底、紫色标题、两列、12mm 边距、10pt 正文。先用本机 Chrome 测量真实块高度，再选入能完整放下的卡片；不截句、不缩小字号强塞，不让卡片跨页。

预览与下载同一份保存的报告，下载不重新生成。速览按概念、金句、资料交错精选，保证三类都有机会进入纸面。逐期两页当前可完整放入四期摘录，剩余材料列在完整十篇来源索引中；网页仍展示全部十篇。精选数量和未收录数量写在报告上，一页／两页是实际生成页数。

导出需要本机 Chrome／Chromium；Windows 使用独立隐藏进程和临时浏览器目录，启动时等待端口文件完整可读。未成功启动或排版失败时 API 返回明确错误，保留原报告。

## 背景检索边界

联网补充针对文稿中实际出现的人物、资料或实体，附网页来源和访问时间，与嘉宾原话明确分开。当前没有启用实时搜索凭证，默认实际使用本轮读过的 EFF、TCL、出版社资料，页面标为“已有检索资料”。不能把它称为 DeepSeek 自带的实时联网结果。

配置现有 Tavily 搜索后可按具体实体检索，单次最多四个查询，结果分别绑定来源。DeepSeek 官方原生搜索与当前第三方 OpenAI-compatible 通道的透传能力仍需单独接入验证，不更改既有 API 配置。

## 主要实现

- `BriefingReportService`：全文抽取、缓存与来源校验、关注项过滤、五版编排和保存。

- `briefing_report_pdf.py`：固定版式、实测排版和 PDF 生成。
- API 路径与权限见 [接口文档](./api.md)。旧单集摘要和旧简报后端接口保留，新入口使用上述内容报告。

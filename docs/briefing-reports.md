# AI 简报：五种内容模式与风格库

2026-10-01。入口 `/briefing`，旧 `/briefing-lab` 链接兼容。原左侧标识、模式切换、节目与订阅、底部设置完整保留。

## 周报与月报

周期按香港时区的节目发布时间计算：周一至下周一为一周，每月1日至次月1日为一个月，区间右侧不包含。日期栏以周报／月报、左右切换和可横向滑动的日期标签浏览，不使用原生范围滑杆；切换日期保留阅读风格和内容模式。

当前周期展示同来源内容去重后的全部材料数、有实际正文的材料数，以及完成正文筛选后的纳入数。不同RSS订阅可使用相同guid，不因此合并或借用彼此的文稿；标准YouTube／B站视频编号可跨重复订阅识别同一期。材料清单可查看具体节目、发布日期、正文是否可用、相关话题与纳入理由。总材料数包含尚无正文的节目；没有正文的材料不会被当作已经分析过的内容。

日期切换只读取已保存结果，不调用模型。不同周期、关注组合和正文指纹对应独立报告；没有该范围的结果时明确提示生成，不回退其他日期的报告。此前固定十篇的对照样例与缓存保留兼容。

账号可在“我的关注”中选择每周或每月自动生成。周期结束后的00:05（香港时间）起，后台每五分钟检查，按最新关注生成最近结束周期的五种模式；同周期已有完整结果则复用。开启前结束的历史周期不会自动补生成。任务按账号和周期持久去重，失败隔一小时重试，最多三次；全局AI关闭时暂停新生成。自动任务依赖后台服务运行，停机后只补最近符合条件的周期，仍可手动生成。

## 我的关注与正文筛选

“我的关注”保存账号的关注话题，可添加、移除与停用，例如AI、LLM；没有保存偏好时提供默认话题。启用的话题用于生成前的取材，卡片上的内容标签仍用于阅读已有报告时的即时筛选。

生成先对本周期已有正文进行连续分块筛选。LLM必须给出关联话题、具体理由和能在正文逐字定位的证据；仅标题含关键词、广告偶然提及或泛泛技术讨论不足以纳入。筛选结果按正文指纹和话题组合复用，关联的材料再进入五种内容分析。查看周期和保存关注不会自动调用LLM；未启用任何话题时纳入该周期全部可用正文。

## 原话浮窗

“原话依据”与“提及原话”打开独立阅读浮窗，保留原卡片尺寸和阅读位置。浮窗可切换多段原话、英文对照，查看节目出处、回听或打开文稿；点击外围和Esc均可关闭。桌面指针移动仅有轻微光感和倾斜，触屏与减少动态效果设置不启用跟随动作。

桌面浮窗固定650×560px，手机与矮屏按可用视口缩小，长短原话和语言切换都不改变窗口尺寸。标题、语言工具、出处和底部操作各自固定区域，只有正文滚动；短句保留留白，长文提示滚动并在尚未读完时轻微渐隐。保留原话分段，不缩小字体或裁掉全文。选中原话后可划下重点，每段原话和译文分别保留一处划线，仅在本次浮窗阅读中保留，可清除；不会改写原文或保存成永久笔记。

## 内容模式决定取材，风格决定呈现

五种内容模式使用各自的生成任务与缓存。核心提要不再用几句摘录代替整期理解；原话模式继续保留简短背景与逐字引用。首页先展示最多六条，有更多内容时可以展开；证据和详细资料仍按需阅读，材料不足时不凑数量。

| 内容模式 | 要回答的问题 |
| --- | --- |
| 核心提要 | 这期主要在讨论什么，提出什么判断，有哪些依据与条件？ |
| 原话精选 | 哪些完整原话值得记下，并能直接回听？ |
| 共性与分歧 | 哪些节目在讨论同一个具体问题，观点如何关联或不同？ |
| 新词与方法 | 出现了什么术语或方法，这期是怎么使用它的？ |
| 提到的资料 | 实际提到了什么书、文章、论文或工具，可以继续读什么？ |

此前十篇对照复核结果为10条核心提要、10句原话、4组有证据的联系、8个新词与方法、10份资料，77处引文均核对原文与节目时间。共性模式包含两组共同点和两组互补，没有为了凑“分歧”制造相反观点。周期报告的数量随实际相关正文而变化，不要求每一期凑相同数量。

2026-10-01对进行中的09月28日—10月04日周期实际试生成：8期都有文稿，AI／LLM正文筛选纳入5期、排除3期历史节目；相关内容共21分块、210,747字符。五种模式为5条核心、8句原话、2组有边界的互补观点、8个新词与方法、8份资料。原文引句均核对偏移和来源，35条英文依据补中文译文；删去两组证据不足的联系，原模型稿与审查依据另存保留。周期尚未结束，自动周报将在周期结束后纳入届时材料。

视觉风格属于独立的风格库，同一模式的内容可以换一种样子呈现，不重新调用模型。风格选择与内容模式选择分别保存。现有排版继续保留，新增风格只需要适配已有内容块，不需要复制分析流程：

| 版式 | 阅读结构 |
| --- | --- |
| 留白 | 一句主摘录，其余分层排布，使用留白和平线 |
| 大字 | 宽幅原话逐句展开，突出文字本身 |
| 清单 | 单列阅读行，快速选择想继续听的内容 |
| 双栏 | 两列原话并排阅读 |
| 纸面 | 应用深色外壳里的浅色阅读页 |
| 报刊 | 暖白底色、衬线标题与双栏，形成报刊式阅读页 |
| 便笺 | 浅黄与浅绿便笺，每块集中展示一个要点 |

来源字体至少13px，原话以20–24px为主，焦点摘录进一步放大。双栏卡片等宽等高，文字区和底部操作对齐；手机恢复自然高度。生成主题设置收起，首页不展示全文字符数、任务配置或资料查证工作状态。

内容标签依据实际内容归类，包括AI、编程、商业、管理、历史与科学。点击只筛选已有结果，不触发生成；账号关注话题则用于前置取材，两者承担不同用途。卡片保留来源与回听入口，方便判断标签对应哪一期的内容。

灰色爱心常驻卡片操作区，收藏后填充彩色，支持再次取消；收藏沿用按账号区分的浏览器存储，不代表跨设备同步。

## 全文取证与精选

此前对照样本为十篇完整文稿：281,782字符、32个连续分块，材料指纹 `aed02d4c400f1a3f`。当前周期入口从订阅库读取所选日期内的材料，不固定限制十篇取材。核心提要优先每期一个主旨；其他模式按内容价值选取，不要求每期占一张。

全文抽取缓存先提供原话与证据，各模式再结合所有分块的阅读记录和已保存的单篇解读生成对应内容。生成说明展示实际使用的模式模板与输入说明。此前 `BriefingReadingService.generate_edition` 明确要求选3–5句原话、不做分类大清单，适合摘句，不能直接代表全部播客核心；该接口保留兼容。

核心提要必须交代具体主张与条件，附对应的正文证据；跨节目分析必须有不同节目的直接支持，不能仅凭共同提到“AI”就称为共识或分歧。明显字幕错词与不完整含义不进入结果。缩短引文只能取原始候选中的连续完整句，并重新定位正文偏移与字幕时间；不能AI改写后标为原话。

说话人由已校验候选继承，身份无法确认就不补人名。播客旁白不能误归为其讨论的历史人物。译文不强设字数下限，避免为凑字数添加原话没有的意义。本轮人工复核保留原始模型结果和编辑理由，原始文稿不改写；用户生成的三份旧模板结果保留原文件，另存带原报告ID、实际调用记录和修订依据的复核副本。

跨节目联系明确标为AI归纳，必须关联至少两个不同来源的原话。没有确切联系就不显示，不制造一致观点、争论或相互印证。资料必须在文稿中实际提及，未验证的链接不能生成或猜测。

## 感兴趣再读单篇

“读这期”在AI简报内部进入单篇解读，保留左侧AI状态；返回时保留排版与阅读位置。单篇先给一句要点，再给一至三个有依据的解读；对应原话与进一步资料主动展开，短片不足三点不凑数。

读取已有结果不调用模型。未生成时给明确生成按钮，使用已读全文分块记录与校验过的证据生成，不能拿标题冒充全文解读。任务按账号隔离，失败保留旧结果，断线保留任务并重试。

“从这里听”复用跨节目定位播放；无法应用内播放时提供原平台时间链接。“查看原文”仍展示保存的完整正文／字幕及定位。单篇阅读与传统节目详情承担不同阅读层级，播放动作才切换至传统模式。

## 封面与导出

封面优先已落地的 `/api/media/covers/` 图片；相对路径不是无效URL。远程图不携带本地页面Referer，失败后尝试订阅图片，最终使用CSS文字／平台图标，避免不存在的占位图造成二次裂图。

一／两页PDF导出当前内容模式保存的结果，预览与下载不重新生成。纸面与报刊使用与网页同源的阅读主题CSS：纸面单栏、报刊双栏，字体、底色与分隔线一致。其他阅读风格可在导出预览中明确选择纸面或报刊。

原话模式的一页保留精选；两页版允许完整原话续排第二页，再补能容纳的英文对照和来源。浏览器按实际列宽测量后分页，不截断原句、不无限缩字号强塞；未收录内容与英文对照标明数量，并保留完整文稿链接。周期材料较多时，纸面索引列出收录内容的来源，完整材料清单通过网页查看。兼容的旧接口仍支持原有固定版式。

旧五种分类报告与原话精选后端接口保留兼容，当前入口使用内容模式与风格库。详细端点见 [API文档](./api.md)，此前内容方案见 [方案记录](./briefing-report-plan.md)。

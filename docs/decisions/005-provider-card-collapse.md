# ADR-005: 设置页服务商卡片折叠为状态灯摘要卡

**状态**: 已实施并提交

**背景**: AI 配置页每个服务商是一张全宽大卡片（API 格式 / 名称 / Base URL / Key / 模型列表 / 手动添加）。服务商配置完成后很少改动，大卡片常驻导致页面越长越长，任务路由等真正高频调整的区域被挤到下方。

**决策**: 服务商卡片支持折叠，采用"状态灯卡"样式：

- 左侧 3px 状态色条常显——绿色 = 已启用，灰色 = 已停用，无需展开即可扫读全局状态
- 折叠态收为一行摘要：名称 + `● 已启用` 状态 + 模型数 + 默认模型名；Key 不显示（展开才可见）
- 已配置 API Key 的服务商在加载/保存后**默认折叠**；未配置 Key 的（新添加）保持展开引导填写
- 点击标题栏切换展开/收起；展开态为原有完整表单不变
- 启用开关、删除按钮独立于折叠点击区，不受误触影响

**备选方案**: 本次共做六种折叠样式 + 一种宫格布局的 HTML 原型对比（极简行 / 头像卡 / 状态灯卡 / 统计徽章 / 终端风 / 双层卡 / 宫格卡片墙）。选状态灯卡的原因：启用状态是服务商列表最高频的扫读信息，色条把它提到视觉第一层；单行摘要对 2-4 个服务商的典型规模信息密度最合适；宫格形态在服务商数量少时反而留白浪费。原型已删除。

**取舍**:
- 选了：状态可见性优先（色条常显）、单行摘要、按 Key 配置情况智能默认折叠
- 限制：折叠摘要不含 Base URL / Key（防止敏感信息常驻屏幕）；折叠状态不持久化，刷新后回到"有 Key 即折叠"的默认
- 后续可选：折叠状态写 localStorage；服务商数量 >5 时切宫格布局

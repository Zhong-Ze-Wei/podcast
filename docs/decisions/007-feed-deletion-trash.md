# ADR-007: 订阅删除走垃圾箱，不做级联硬删

**状态**: 已实施

**背景**: 删除订阅源时剧集怎么处理？旧实现硬删（曾留下 144 集孤儿——剧集还在但源没了，自动补捞永远扫它们）；直接级联硬删又太狠——字幕是花大力气抓的、摘要花了 LLM 钱，误删无法挽回。

**决策**: 垃圾箱模式（`trash_service`）：
- 删源 → 剧集 + 字幕 + 摘要 + 个人状态整体**搬进 `trash` 集合**（每集一桶，避开 16MB 限制）
- 保留 30 天；期间**重新订阅同一来源自动捞回**（按规范化 URL / 频道 ID 匹配，guid 去重，字幕摘要原样恢复）
- 后台每日物理清除过期桶；孤儿剧集（源已不存在）由 `trash_orphan_episodes` 清入桶

**为什么是搬进独立集合而不是软删标记（`deleted_at`）**：
- 搬走后正常查询天然看不到，**不需要给全站查询加 deleted 过滤**——软删方案要改每一个 episodes 查询，漏一处就脏数据
- 捞回就是搬回来，没有中间状态

**取舍**:
- 选了：30 天可后悔 + 零查询侵入
- 限制：捞回依赖重新订阅（没有独立回收站 UI）；孤儿剧集入桶时没有源信息，只能等过期清除

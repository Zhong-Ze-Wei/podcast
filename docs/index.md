## 内容边界

- **快速启动**只管"从零到能用"：环境、安装、配置、首次使用流程。不解释架构。
- **架构概览**只管"系统长什么样"：分层、数据流、权限模型。字段和端点细节分别归数据库篇和 API 篇。
- **数据库设计**是 schema 的唯一真源，含数据治理决策（弃用字段、隔离原则）。以代码和 `app/__init__.py` 的索引定义为准。
- **API 接口**是端点的唯一真源，从 `backend/app/api/` 提取，含角色要求和响应格式。
- **AI 功能**讲机制与产品策略（三层字幕、全局 LLM、模板引擎），不重复字段表。
- **待办与决策**只收"已调研、未实施"的事项和产品决策记录；实施完成的事项移入对应文档。

## 维护规则

文档改代码时同步改：新增端点 → `api.md`；集合变更 → `database.md`；行为决策 → ADR 或 backlog。三处真源（代码、database.md、api.md）不一致时，以代码为准并修文档。

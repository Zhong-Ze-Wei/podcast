LLM API 端点配置：六种 UI 策略

目标是让 OpenAI 兼容端点配置更清楚：用户知道当前激活的是谁、密钥保存状态如何、测试连接结果是否可信、常见 Provider 如何快速填入，同时不要把敏感信息暴露在主界面。

适合 AI 功能很多的应用。先展示“当前能不能用”，再展示配置字段。优点是排错效率高；缺点是占用空间较大。

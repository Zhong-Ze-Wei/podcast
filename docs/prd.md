# PRD - 产品需求文档

> Podcast Manager v1.0
> 文档日期：2026-05-16

---

## 1. 产品定位

**目标用户**：有大量英文播客订阅、希望高效消费内容的知识工作者（投资者、研究员、学习者）。

**核心价值**：把"听播客"这件耗时的事，变成"读摘要、筛选精华、按需深入"的结构化知识消费流程。

**一句话定位**：播客的 AI 阅读助手。

---

## 2. 核心用户旅程

```
订阅 RSS → 自动拉取单集 → 下载音频 → 生成转录 → AI 摘要 → 阅读/播放
```

## 4. 技术规格

| 层 | 技术选型 |
|----|----------|
| 前端 | React 18 + Vite + TailwindCSS + i18next |
| 后端 | Python 3.12 + Flask + Flask-CORS |
| 数据库 | MongoDB（单机，无 Replica Set） |
| AI 转录 | AssemblyAI（云端，需 API Key） |
| AI 摘要/翻译 | OpenAI 兼容 API（可接任何兼容接口） |
| 搜索增强 | Tavily API（已集成，前端未使用） |
| 异步任务 | Python ThreadPoolExecutor（内存 + MongoDB 双写） |
| 媒体存储 | 本地文件系统 backend/media/audio/ |

---

## 5. 非功能需求

| 项目 | 描述 |
|------|------|
| 安全 | RSS URL 做 SSRF 防护（禁止内网 IP / localhost）|
| 并发 | 任务队列 3 个 Worker 并行（可配置） |
| 国际化 | 中/英双语界面（i18next），前端文案全部外化 |
| 数据持久化 | 任务状态内存 + MongoDB 双写，重启后可恢复 |

## 6. 已知问题与技术债务

### 高优

| 问题 | 描述 |
|------|------|
| 本地音频播放缺失 | 音频下载到本地后，`audio_path` 存入数据库，但前端播放器仍用 `audio_url`（远程地址），无法播放本地文件 |
| 搜索未实现 | 前端有搜索输入框，实现为纯本地过滤（仅过滤内存中已加载的单集），后端无搜索 API |
| insights API 状态描述过时 | `plan.md` 中标注为 placeholder，实际已实现（含 PDF 导出） |
| 前端 `insightsApi` 实现 | `api.js` 中已有 `insightsApi` 但 `AIBriefingView` 组件是否完整使用需核查 |

### 中优

| 问题 | 描述 |
|------|------|
| 无用户系统 | 单用户场景，无认证、无权限 |
| 摘要导出 | 转录/摘要内容无法导出（仅简报支持 PDF）|
| Tavily 配置未暴露 | 后端已有 Tavily 配置接口，前端无对应 UI |
| 字幕版本不一致 | `summary_type` 旧字段与 `template_name` 新字段并存，数据库中可能有 v2/v3 混合数据 |

### 低优

| 问题 | 描述 |
|------|------|
| 分页实现不完整 | 前端一次性请求 `per_page=500` / `per_page=1000`，数据量大时有性能风险 |
| AssemblyAI Key 管理 | AssemblyAI API Key 目前通过 `.env` 硬编码，无 UI 配置入口 |
| 无 Docker Compose | README 提到 Docker 需求但项目无 Dockerfile / compose 文件 |
